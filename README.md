# StepOutr landing page

The static marketing page for StepOutr, hosted on GitHub Pages.

This repo exists only because the main `stepoutr` app repo is private, and
GitHub Pages on a private repo needs a paid plan. This one is public and
holds nothing but the page itself — no app source, no secrets.

**Source of truth:** this is a mirror. The page is developed in the main
`stepoutr` repo's `landing/` folder (private) and copied here when it
changes. If you're reading this from here wondering how something works,
the real history and reasoning live there.

**Live at:** https://priyamragpt.github.io/stepoutr-landing/
